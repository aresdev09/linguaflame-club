# Ручные проверки в тестовой группе (этап 12, задачи 12.2–12.4)

Подготовьте **тестовую группу** и **2–3 аккаунта**: один — администратор
группы, остальные — обычные участники. Отмечайте пункты по мере проверки.
Если пункт не сходится — запишите ожидаемое и фактическое поведение.

## Подготовка

- [ ] Бот добавлен в тестовую группу, бот запущен (`python -m bot.main` или
      `docker compose up`), в логе есть строка о старте.
- [ ] В логе нет ошибок конфигурации; `BOT_TOKEN` и `AI_API_KEY` заданы.
- [ ] Админ выполнил `/setup` и задал: уровень, языки, часовой пояс, время
      поста, что публиковать, тихие часы.

## 12.2 Команды, игры и перезапуск (2–3 аккаунта)

### Онбординг и справка

- [ ] `/start` в личке: приветствие и кнопка «Add to group»; кнопка открывает
      выбор группы.
- [ ] `/help` в личке: список команд по ролям.
- [ ] `/quiz` в личке: вежливый отказ «работает в группе», а не тишина.
- [ ] `/help` в группе: короткая справка по ролям.

### Настройки группы

- [ ] `/setup` у админа открывает меню с галочками на текущих значениях.
- [ ] Кнопки меняют уровень, слова/грамматику дня, число слов, язык интерфейса,
      язык переводов, часовой пояс, время поста, тихие часы; меню
      перерисовывается с новым значением.
- [ ] «Ввести часовой пояс вручную»: бот просит ответить reply; корректный
      пояс сохраняется, некорректный — понятная ошибка.
- [ ] «Ввести время вручную»: `09:00` сохраняется, `25:00` — ошибка.
- [ ] `/settings` показывает те же настройки.
- [ ] Обычный участник на `/setup` получает отказ «только админы»; повторный
      `/setup` в течение минуты не спамит (отказ не повторяется).
- [ ] Имя бота отображается в интерфейсе выбранным языком (en/ru).

### Квиз

- [ ] `/quiz` без аргумента запускает 5 раундов; `/quiz 3` — 3; `/quiz 20`
      ограничивается 10; `/quiz abc` играет стандартные 5.
- [ ] Кнопки A–D: верный ответ начисляет очки, неверный — сообщение об ошибке.
- [ ] Один участник отвечает один раз за раунд: повторное нажатие отвечает
      «уже отвечали».
- [ ] По истечении времени раунда ответ не принимается («время вышло»).
- [ ] После последнего раунда приходит итог с очками; кнопки старого раунда
      больше не принимают ответы.

### Мини-игры

- [ ] `/games` показывает меню; каждая кнопка запускает свою игру.
- [ ] `/scramble`: ответ принимается **reply** на сообщение раунда, обычное
      сообщение не считается ответом.
- [ ] `/gap`: ответ кнопкой; верный/неверный/повторный варианты обрабатываются.
- [ ] `/race`: быстрый верный ответ даёт больше очков, чем поздний.
- [ ] `/truefalse`: кнопки «Правда»/«Ложь».
- [ ] Одна игра на группу: пока идёт игра, вторая команда отвечает «игра уже
      идёт».
- [ ] Кулдаун между играми: сразу после окончания игра не стартует.

### Слова и грамматика дня

- [ ] `/word` показывает слова дня; повторный `/word` в тот же день показывает
      тот же пост (без нового запроса к ИИ).
- [ ] Кнопка «Got it» начисляет очки один раз; повторно — «уже получили».
- [ ] `/grammar` показывает грамматику дня; «Show answer» открывает ответ;
      повторно — «пост неактуален».
- [ ] У двух групп одного уровня и языка в один день приходит одинаковый
      контент (общий кеш).

### Рейтинг и огонёк

- [ ] `/top` показывает рейтинг за неделю; кнопка «All time» переключает период.
- [ ] `/me` показывает личные очки, место и точность.
- [ ] `/streak` показывает текущую серию, рекорд и активность сегодня.
- [ ] Очки за игру/пост появляются в `/top` и `/me`.

### Админ-команды

- [ ] `/stop` во время игры останавливает её; очки закрытых раундов сохранены.
- [ ] `/stop` без игры отвечает «нет активной игры».
- [ ] Обычный участник на `/stop` и `/reset_scores` получает отказ.
- [ ] `/reset_scores` показывает подтверждение; «Cancel» ничего не меняет;
      «Confirm» обнуляет рейтинг и предлагает «Undo reset».
- [ ] «Undo reset» возвращает очки; повторный откат — «нет свежего сброса».
- [ ] Анонимный админ (включите «анонимность» в правах админа) может выполнить
      `/setup` и `/stop`.
- [ ] `/privacy` показывает, что хранит бот; «Hide from leaderboard» убирает
      участника из `/top`, «Show» возвращает.

### Перезапуск бота посреди игры

- [ ] Запустите `/quiz`, ответьте на 1–2 раунда, не дожидаясь конца
      перезапустите бота (Ctrl+C и снова старт, или `docker compose restart bot`).
- [ ] После старта рейтинг (`/top`, `/me`) сохранился.
- [ ] «Зависшей» игры нет: либо игра продолжается, либо помечена просроченной;
      новая игра запускается без ошибки «уже идёт игра».
- [ ] Пост дня не отправляется повторно после перезапуска.

## 12.3 Группа с темами (forum) и миграция в супергруппу

- [ ] Включите в группе темы. `/setup` внутри темы: пост дня уходит в эту же
      тему.
- [ ] `/quiz`, `/games`, `/word` внутри темы: сообщения и кнопки приходят в ту
      же тему.
- [ ] Автосообщения планировщика (пост дня, напоминание) приходят в тему,
      выбранную при `/setup`.
- [ ] Переведите обычную группу в супергруппу (Настройки → «Преобразовать в
      супергруппу»). После миграции:
- [ ] Данные группы сохранились: рейтинг, настройки, огонёк (id чата
      обновился).
- [ ] Команды в супергруппе работают; пост дня приходит по расписанию.

## 12.4 Права бота и удаление из группы

- [ ] Бот **без администраторских прав**: `/setup`, игры, `/word`, `/top`
      работают (админские права нужны только для чтения истории/удаления, но
      не для работы бота).
- [ ] Проверьте, что бот не требует прав для отправки сообщений: ошибок «не
      достаточно прав» в логе нет.
- [ ] Удалите бота из группы. Бот перестаёт отправлять автосообщения.
- [ ] В логе есть отметка, что чат недоступен/помечен неактивным; бот не падает.
- [ ] Добавьте бота обратно. Приходит приветствие, настройки и рейтинг
      сохранились, команды снова работают.

## Если что-то не так

- Соберите фрагмент лога вокруг ошибки (при `LOG_JSON=true` — JSON-строки).
- Проверьте `SCHEDULER_TIME_OFFSET=0` (сдвиг не должен остаться включённым).
- Для сброса проверки планировщика смотрите README, раздел «Ручная проверка
  планировщика».
